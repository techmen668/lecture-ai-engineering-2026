- 取り組んだレベル：基礎

    どちらの設定でも JSON の形式は守れました。今回の結果では、10 エポックの内容正解率が 20 エポックより約 4.8 ポイント低く、退行が 2 問ありました。

    ただし、10 エポック実行の学習前評価が format_rate 1.000、content_rate 0.905 で、20 エポック実行の学習後評価と一致していました。20 エポック実行時の学習前評価（0.095、0.000）と大きく異なるため、同じ条件での比較になっていない可能性があります。ランタイム再起動後に先頭から実行し、学習前評価を取り直して確認する必要があります。

    `result.json` の `seconds` は評価にかかった時間であり、学習時間ではありません。最終 loss と学習時間は、学習セルの `Training Loss` と `学習時間: ... 秒` の表示を確認して記録します。

- ファインチューニングが向く場面・向かない場面についての考察：

    今回は 10 エポックでも JSON 形式の遵守率は 100% でしたが、内容正解率は 20 エポックの結果より低くなりました。出力形式や定型的な回答の学習にはファインチューニングが役立つ一方、学習回数だけで未知の質問への判断や正確さが保証されるわけではありません。特に、FAQ にない質問へ根拠なく回答する失敗を防ぐには、学習だけに頼らず、検索で根拠を確認する仕組みや、確認を促す設計も必要です。今回の学習前評価に差があるため、エポック数による差の結論は、条件を揃えて再確認してから出します。
